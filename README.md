# Anna's Personal Website

A clean and modern personal website for Anna.

## Features

- Responsive design that works on all devices
- Modern, gradient hero section
- About section to introduce yourself
- Skills showcase with interactive cards
- Projects portfolio
- Contact section

## How to View

Simply open `index.html` in your web browser to view the website locally.

## How to Deploy

### GitHub Pages

1. Go to your repository settings
2. Navigate to "Pages" section
3. Under "Source", select your main branch
4. Your site will be published at `https://yourusername.github.io/azle/`

### Other Hosting Options

You can also deploy this website to:
- Netlify (drag and drop the files)
- Vercel
- Any static hosting service

## Customization

Feel free to customize the content by editing:
- `index.html` - Update the text, sections, and structure
- `styles.css` - Modify colors, fonts, and styling
